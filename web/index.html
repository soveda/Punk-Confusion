Roll your own shouts.

Drop four short vocal samples here. The browser converts them to the card format and builds a replacement VocalSamples.h.

Target format 24 kHz mono signed 16-bit PCM, normalised to about -6 dBFS.
Firmware flow Download samples/header, run the build script, flash the custom UF2.
Keep it short The card targets 2 MB flash. Short shouts are the point.

What gets generated?

The output header uses the same symbol names as the firmware: kVocalMarqueeOi, kVocalCbgbHeyHo, kVocalClub100NoFuture, and kVocalWhiskyLetsGo. The web tool does not compile firmware directly. For a full custom UF2, download the processed WAVs, put them in a folder, then run python3 tools/build_custom_uf2.py --samples that-folder --clean.
